# rgbdns-reader (retired)

This was the vault's title-specific reader plugin (0.2.0). The vault now
bundles FirstPair Reader 2 (`firstpair-reader`) from the FirstPair checkout,
which replaces it: the standard rail, and fragment cards whose Show code and
Open file actions resolve the code lines that this plugin's `codeNote#heading`
jump never reached. The builder no longer installs this folder and removes it
from rebuilt vaults. It is kept for reference only; see
`docs/OBSIDIAN-VAULT.md`.
